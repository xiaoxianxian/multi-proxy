## 1 · 架构师（严重强迫症·较真）

**审什么：** 分层清晰度、数据契约真实性、doc-vs-code 一致性、门控安全、信任边界。

  - 信任边界铁律贯穿：用户价格主权 > 官价（漂移 toast 永不自动覆盖）；用户路由主权 > 引擎建议（override 仅建议）。

- **F1（必修·较真项）**：架构 §3.7 第 173 行明确标注 `deepseek-v4-pro 0.5/3/0.02（改！现 1/4/0.02）`，第 186 行"1/4/0.02→0.5/3/0.02 回官方……这是本轮要修的真实偏差（影响路由比价）"。但 `routeEngine.ts:206` 实测仍为 `{input:1, output:4, cacheHit:0.02}`——**代码未动**。架构已标注、属 P1 待办（符合"不抢开发"），但较真口径要求：**P1 开发第一步必须修 deepseek 价 + 加源/日期注释**，否则路由比价用错值。

**架构师裁定：PASS·有条件。F1/F3 P1 前必修；F5 建议。**

## 3 · 前端工程师

**审什么：** `q1-ux-design-v1.md`（354 行，3 表面 A/B/C）的复用契约是否落在真实代码。

- **通过项（实证）：**
  - `.toast-container`（`shared-styles.css:142`）+ `.toast.{success/error/info/warning}`（:171/177/182/187）+ 暗色映射（`:root.dark` :408-420）+ `.offline-banner`（:686）全部 grep 命中——CSS 层复用真实。
  - `BroadcastChannel('proxy-status')` 实证在 `proxy-config.html:994-996` / `dashboard.html:2016-2018` 双处，跨页刷新机制真实存在。
  - `loadStatus()`（`dashboard.html:1789`）实证存在。
  - 可访问性债标注准确：UX 稿 §0 引 `09-review/8-UI设计师.md §八`，识别"toast 无 role/aria-live、modal 无 role=dialog/Esc/焦点陷阱"，3 表面强制补债——诚实。

- **F3（必修·较真项）**：UX 稿 §0 通知通道写"复用 `multi-proxy-manager/public/shared-styles.css` 的 `showToast(msg, level, ms)`"，但实证：
  - `showToast` 是 **JS 函数**，不在 `shared-styles.css`（那里只有 `.toast` CSS 类）；
  - 4 处调用签名**不统一**：`proxy-config.html:1916 function showToast(msg, type)`（2 参，无 ms）；`dashboard.html:1000`、`logs.html:802`、`sessions.html:160` 均 `(msg, type, duration)`（3 参）。

- **F4（建议）**：3 个表面的 `role=status aria-live` / `role=dialog aria-modal` + 焦点陷阱 + 焦点归位是"实现期强制项"，UX 稿已列但无组件级落点建议。建议 P1 给一个 `a11y-toast`/`a11y-modal` 最小封装，3 表面复用，避免三处各写一遍焦点陷阱。

**前端裁定：PASS·有条件。CSS 层复用真实；showToast 签名 drift（F3）P1 前必修；F4 建议加 a11y 封装。**
