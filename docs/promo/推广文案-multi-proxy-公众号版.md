## 一、先说那个 502

我本机上同时装着 Codex、Claude Code、Cursor，还有一个 cc-switch 占着 15721。某天开始，其中一个工具的日志里全是 502，模型明明没错、Key 也没过期。查了半天才反应过来：那个 agent 的 `base_url` 被两个工具同时认领了，请求到底发给了谁，取决于谁最后启动。

这类事的特点是，它不在任何一个工具的报错信息里。每个工具都认为自己是唯一的主人在配置这个 agent，报错只会告诉你"连不上"。

## 二、为什么云端网关管不了这件事

最近大厂在做云端 AI 网关（火山 AgentKit、阿里云 AI 网关都在做），多模型统一入口、密钥托管、计量分账、内容过滤，一套组织级服务。它们解决的是组织的问题，这台机器上的事不在它们的射程里。

判断一个 agent 的 `base_url` 被谁占了，需要读这个 agent **自己的配置文件**。cc-switch 写在它的库里，Cursor 写在它的设置里，Hermes 写在 `~/.hermes/config.yaml` 里。这件事只有跑在你机器上的进程做得到，远端服务读不到你本机的配置文件，也无从知道哪个工具刚把谁的配置覆盖了。

还有一层容易搞混：端口在听，不等于它正在代理这个 agent。只扫端口会把"15721 有人占着"当成"cc-switch 正在接管 Codex"，而真相可能只是别的服务碰巧用了那个端口。正确的做法是读配置里 `base_url` 的实际指向，光看谁在听会判错。

## 三、我的解法：先问所有权，不抢线

我做的 multi-proxy 里有一条结构化解法：**同一时刻，一个 agent 的 `base_url` 只能有一个所有者。**

- 开代理前先 `detectAll()`，读各 agent 自己配置文件里 `base_url` 的实际指向；
- 发现目标 agent 已被别的工具认领，就把这个 agent 的开关置关并提示，**不抢、不覆写**；
- 真要换所有者，走 `tools/agent-proxy-switch`，切之前先确认目标端口真的在听，而且只改这个 agent 自己的配置，不误伤别家。

占用者端口表 `OCCUPANT_PORTS` 默认 15721（cc-switch），可以用环境变量扩展。这条能力来自一次真实事故：我往全局 launchd 注入了带裸 `*` 的 `NO_PROXY`，本机所有走代理的 GUI 应用把"所有域名"判定成不走代理，全部直连超时。从那以后我把教训固化成了代码。

## 四、三笔工程账

多模型路由聚合这件事本身不稀缺，LiteLLM、one-api、New-API、TierFlow 都在做。**"支持本地模型"也不是差异项**，别拿它当卖点。真正难抄的是这三笔：

1. **用量归一的自动识别。** 只靠 usage 字段名形态就能认出不同供应商的记账口径，接入方贴一段上游原样 JSON 就够了。各家字段长得不一样，Anthropic 的流式还在末事件里再包一层，硬写三份解析器在跨版本升级上会反复返工。
2. **一个 agent 的 `base_url` 同一时刻只有一个所有者。** 就是第二节那件事，上下文不在代码里，是从事故里长出来的。
3. **本地是一档路由条件，不是一个开关。** 路由规则打上 `privacy=true`，下游地址就是 `127.0.0.1`，是架构性保证，不是调参调出来的效果。

另外还有一条边界：5 个适配器只读 agent 的状态与结果，**绝不写回** agent 任何配置文件；编排默认影子模式，先记账，不动真实流量。

## 五、没做的和过重的，先摆出来

- **MCP 管理、内容过滤、全链路日志，我这边没做。** 云网关在这些项上是现成答案，我不嘴硬。
- **只想省 API 的钱、要一个两分钟跑起来的网关，这个 repo 过重。** 它是为"本机多个 agent 同时在跑、数据不能出这台机器"这一层做重的，单端口轻量网关更合适。
- **本地这一层的代价自己扛**：一台机器的看护、升级、故障单点。算完这些还选本地，才是真需求。

## 六、选型看你在哪一层

组织要合规分账、要统一管控，云网关是现成答案；你一个人或一个小团队，本机上跑着好几个 agent、想知道钱花在谁身上、想让本地模型进同一张路由表，本地这一层就得有人站。两层按需叠加，叠着跑的时候你手上会有两本账，云网关一本、本地一本。本地那本不是重复建设，是你对账的底稿。

multi-proxy 在 GitHub 上公开，搜项目名能找到。当前 7 个代理适配器（codex / claude / hermes / cursor / opencode / generic / dsh）加一个管理面板，测试基线最近一次跑完全绿：manager 1458、generic 177、claude 174、codex 159、opencode 159、cursor 250、hermes 77、dsh 20，另有 l2 demo 51 与 shell 11。

我的东西不神秘，也不打算替你做决定。你按自己所在的层选。
