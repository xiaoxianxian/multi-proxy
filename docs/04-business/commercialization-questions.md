## 一、市场判断（5 问）

| # | 问题 | 本项目现状锚点 | 决策 |
|---|------|----------------|------|
| 1.1 | 目标市场是什么？（B 端 SaaS / 开发者自部署 / 企业内部私有化） | 全本地 Harness（4 proxy + L2 编排都在本机跑），天然贴合私有化；vs OpenAI 托管版要信任其运行 Harness | ☐ |
| 1.2 | 直接竞品是谁？ | OpenAI Harness（托管）、AutoGPT/LangGraph/CrewAI（编排框架）、cc-switch（多代理切换，独立 App 15721） | ☐ |
| 1.3 | 差异化凭什么成立？ | 「全本地」比 OpenAI 托管更彻底（Harness+执行器都自管），私有化程度更高——但私有化是需求还是卖点取决于目标客户 | ☐ |
| 1.4 | 时机窗口在哪？ | 本地大模型（Qwen3.8-27B/MLX）已能扛 judge/decompose，本地执行者成熟度够 | ☐ |
| 1.5 | 市场够大吗？愿意先服务谁？ | 未做过客户访谈，纯技术视角推断——需老板补市场信号 | ☐ |

## 二、客户与场景（4 问）

| # | 问题 | 本项目现状锚点 | 决策 |
|---|------|----------------|------|
| 2.1 | 谁付费？（个人开发者 / 小团队 / 企业） | 4 个 proxy 管理 4 类 agent（codex/hermes/cursor）+ 智能路由，形态像「开发者的 agent 运维台」 | ☐ |
