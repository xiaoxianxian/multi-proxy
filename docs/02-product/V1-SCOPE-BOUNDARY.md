## 1. v1 战略定位（一句话）

multi-proxy 的 v1 **不是"模型代理工具"**，是 **AI 时代基础设施中枢 = 中台 + 网关 + 治理**：

- 把 Codex / Hermes / Cursor 等 AI 编程代理当作"员工"，统一管配置（记忆 / 技能 / 路由 / 健康）、统一调度、统一看清运行状态。
- v1 标准：四层架构完整、基本链路打通、大部分核心模块就位。**v1 之后只细化、完善、添砖加瓦，不重定架构。**

## 3. v1 量化验收判据（可测，全过即可交付）

1. **四层覆盖**：代理层 / 网关层 / 中台层 / 管理界面层 每层至少 1 个可运行模块（已满足）。
2. **端到端链路通**：一次请求走完 `代理 → 网关(协议转换+路由) → 中台(route-engine 决策) → 执行 → 回结果`，全链路无断点。
3. **管理面板可用**：18792 能看 3 个 proxy 运行状态 + 启停 + 日志 + 配置编辑。
4. **测试基线全绿**（真值，必须真跑不抄）：manager 770 / codex 62 / cursor 219 / hermes 77 / l2 demo 全绿。CI 绿即为准出门槛。
5. **对外定位文档就绪**：一份讲清"中台 + 网关 + 治理"三层、适用场景、卡位的文档（非使用手册），用于推广清晰。
