口径与边界
只读 + 只算，一个字节都不落
• token 是估算口径（长度/3，复用 token-policy.estimateTokens），不是真实分词器、不是 provider usage；对外引用请标「估算」。
• null = 没量过，绝不拿 0 冒充 —— 平铺 md 没有单体 SKILL.md，量不了就显示 —。
• SkillSwitch 列是外部工具 DargonLee/skill-switch 的五件套（claude/codex/gemini/cursor/windsurf）覆盖范围；否 = 它管不到，但这正是本机 skill 的大头。
• 嵌套 = hermes / workbuddy 用分类目录（skills/<category>/<name>/SKILL.md），扫描已下探一层。
• .disabled 后缀约定抄自 whale2002/skills-switch，未在宿主上逐个验证生效，此处只如实标出来。
