Multi-Proxy Manager · 本地 AI 模型代理管理台

这个工具做什么

  • 在你本机统一管理多个 AI 模型代理（codex / hermes / cursor 等），做路由、成本、健康与告警。
  • 所有代理状态、provider 配置、密钥、账单账本默认仅保存在本机（~/.multi-proxy-manager/ 等本地文件）。
  • 管理面板默认只绑定本回环 127.0.0.1，不对外部网络开放。

隐私与数据

  • 本地优先：默认无任何遥测、无第三方上报；会话 / 成本数据留在本机。
  • 仅当你显式开启对应门控能力（如告警、外部接入端点）时，相关数据才按该能力的设定处理；每个能力默认关闭、可关。
  • 调用上游模型时，你的请求内容由上游模型服务商按其条款处理，本工具不额外留存。
摘要性质。完整用户协议与隐私条款随 v1.0 正式发布时补齐（本工具为本地开源管理面板，无独立法人条款）； 当前以「本地优先 + 每能力默认可关」为实际约定。勾选下方即表示你已知悉并同意继续。
